⚠️  IF AUTOMATED FIX FAILS:

Nuclear option (complete reset):
1. Backup: python manage.py dumpdata > backup.json
2. Delete: rm db.sqlite3
3. Drop MySQL tables:
   mysql -u USER -p DB_NAME -e "DROP TABLE IF EXISTS user_acls, mosquitto_users, mosquitto_acls, mosquitto_superusers;"
4. Migrate: python manage.py migrate
5. Restore: python manage.py loaddata backup.json
